# Your Name — Portfolio

A responsive personal portfolio built with semantic HTML5, CSS3 (Grid and Flexbox), and vanilla JavaScript. No build step or package installation is required.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Personalize before publishing

- Replace “Your Name,” “YOUR NAME,” and “Your City” in `index.html`.
- Change `hello@example.com` to your email address and update the LinkedIn and Instagram links.
- Replace the example project names and descriptions with your own work.
- Update the page title and meta description in `index.html`.

## Publish with GitHub Pages

1. Create a GitHub repository for the portfolio and push these files to its `main` branch.
2. In the repository, open **Settings → Pages** and set the build and deployment source to **GitHub Actions**.
3. The included workflow deploys the site on every push to `main`. Follow its progress in the **Actions** tab; the published URL appears in the `github-pages` deployment environment.

## Week-by-week milestones

- **Week 1 — Setup and requirements:** establish the project, review the requirements, and complete the initial Day 1–3 setup tasks.
- **Week 2 — Core implementation:** build the portfolio’s primary experience and content.
- **Week 3 — Testing and review:** check responsive layouts, keyboard navigation, and browser behavior; complete debugging and CIA-assisted code/content review.
- **Week 4 — Final polish and submission:** personalize content, verify deployment, polish the README, and prepare the project for submission.
